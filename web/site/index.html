ECG Heartbeat Classifier

A small neural network that sorts single heartbeats into five types. It runs entirely in your browser with ONNX Runtime Web. Nothing is uploaded anywhere.

Result

Confidence is temperature-calibrated (T = 1.74, fit on held-out beats), so a reported 90% means roughly 90 out of 100 such beats are classified correctly. This is a research demo, not a medical device. Do not use it for diagnosis.

About the model

Feed-forward network (187 inputs, hidden layers of 256, 128 and 64 ReLU units, 5-way softmax), trained on the MIT-BIH Arrhythmia Database heartbeat set (109,446 beats, five AAMI classes: normal, supraventricular ectopic, ventricular ectopic, fusion, unknown). On a held-out-style test split it reaches 98.8% accuracy, but that split mixes beats from the same patients in train and test, so it is optimistic. A stricter patient-grouped evaluation is reported in the project README. The browser model is the same network converted to ONNX. Full analysis, code and numbers: github.com/nepalanurag/ecg-classification-web.

Data: MIT-BIH Arrhythmia Database, PhysioNet (Moody & Mark 2001). Research demo only.
